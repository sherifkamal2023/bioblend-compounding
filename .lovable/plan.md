## Technical details

- **Routing**: TanStack Start file routes — `src/routes/index.tsx`, `about.tsx`, `services.tsx`, `contact.tsx`. Each defines its own `head()` with unique title/description/og tags. Shared `<Header />` and `<Footer />` mounted in `__root.tsx` around `<Outlet />`.
- **Design tokens**: define palette, gradients, and shadows as semantic tokens in `src/styles.css` (`--brand-navy`, `--brand-teal`, `--brand-red`, `--brand-gold`, `--brand-cream`) and map them via `@theme inline` so Tailwind utilities (`bg-primary`, `text-accent`, etc.) resolve correctly. No hardcoded color classes in components.
- **Fonts**: load via `<link>` tag in `__root.tsx` head (Cormorant Garamond + Work Sans from Google Fonts) — never via CSS `@import` per Tailwind v4 constraints.
- **Components**: shadcn `button`, `card`, `accordion`, `input`, `textarea`, `sonner` (toast). New components in `src/components/`: `Header`, `Footer`, `Logo` (inline SVG), `Hero`, `PillarCard`, `ServiceCard`, `ContactForm`, `SectionHeading`.
- **Assets**: generate 3–4 supporting images with imagegen (compounding lab close-up, pharmacist portrait placeholder, marble hero backdrop, ingredients flat-lay). Uploaded reference images are branding only and won't be embedded directly.
- **SEO**: unique metadata per route, semantic HTML, single H1 per page, alt text on all images, JSON-LD `Pharmacy` schema on home route.
- **No backend** in this pass (Lovable Cloud not enabled). Contact form is presentational; we can wire persistence + email later on request.
